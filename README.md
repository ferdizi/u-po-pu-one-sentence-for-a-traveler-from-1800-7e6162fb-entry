One sentence of 142 characters explaining the modern internet to someone
arriving from the year 1800, built from things they already knew — a post
office, a letter, a library — and a single image: a letter that carries a
whole library and reaches the far side of the earth before the ink dries.

> The internet is a post office where every letter you send carries a whole library, and reaches the far side of the earth before the ink dries.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/traveler-out node main.ts
```

The program reads `entry.txt`, checks it is a single sentence of 1 to 200
characters, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads the
output back and refuses to finish unless it matches byte for byte.
